Microsoft 365 Copilot is Microsoft's AI assistant for everyday work. It can draft and summarise text, answer questions and generate images, in the same way as tools like ChatGPT or Google Gemini.

Everyone in the Defra group has [Copilot Chat](https://m365.cloud.microsoft/chat), the web version included in the standard Microsoft 365 suite. You sign in with your Defra account. There is nothing to request or install.

## What data you can use with it

Copilot Chat runs inside Defra's Microsoft 365 tenant. The same security and data protection that cover your email and documents apply to it, which is what sets it apart from public tools like ChatGPT.

## Why we are using it

Copilot is Defra's default AI tool. It is adopted across the Defra group, everyone already has it, and the AI Unit supports it and writes the guidance for using it.

## When to use it

Use Copilot Chat for everyday tasks where you would otherwise reach for a public AI tool, such as:

- drafting, rewriting or summarising documents and emails
- asking questions and exploring a topic
- generating images

For writing code, use [GitHub Copilot](/ai-toolkit/tools/github-copilot). For building AI into a service, see the platforms and frameworks on the [tools radar](/ai-toolkit/tools).
